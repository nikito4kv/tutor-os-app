# 04 — Маршруты `(admin)`, сайдбар, i18n, верификация

Весь UI следует `docs/DESIGN.md` (токены, типографика, состояния, окна, a11y,
тёмная тема).

## Структура маршрутов

URL: `/admin` (дашборд) и `/admin/feedback` (инбокс).

```
src/app/(admin)/
  layout.tsx                 # await assertAdmin(); <AdminSidebar/> + <main>; БЕЗ SupportWidget
  admin/page.tsx             # const stats = await getAdminStats(); <AdminStatsCards stats={stats}/>
  admin/loading.tsx          # Skeleton-сетка карточек (резерв высоты)
  admin/error.tsx            # "use client"; <ErrorState onRetry={reset}/>
  admin/feedback/page.tsx    # parseFeedbackFilter(searchParams.status) → listFeedback → tabs + list/EmptyState
  admin/feedback/loading.tsx # Skeleton-строки списка
  admin/feedback/error.tsx   # <ErrorState onRetry={reset}/>
src/components/layout/admin-sidebar.tsx
```

### `(admin)/layout.tsx`

```tsx
import { AdminSidebar } from "@/components/layout/admin-sidebar";
import { assertAdmin } from "@/lib/auth";

export default async function AdminLayout({ children }: { children: React.ReactNode }) {
  await assertAdmin(); // не залогинен → /login; не админ → /students
  return (
    <div className="flex h-screen">
      <AdminSidebar />
      <main className="flex-1 overflow-y-auto">
        <div className="container py-8">{children}</div>
      </main>
    </div>
  );
}
```

Без `<SupportWidget/>` — он tutor-only (комментарий в `(app)/layout.tsx`).

### `(admin)/admin/page.tsx`

```tsx
import { getAdminStats } from "@/features/admin/queries";
import { AdminStatsCards } from "@/features/admin/admin-stats-cards";
import { t } from "@/lib/i18n";

export default async function AdminDashboardPage() {
  const stats = await getAdminStats();
  return (
    <div className="space-y-6">
      <h1 className="text-2xl font-semibold">{t.admin.title}</h1>
      <AdminStatsCards stats={stats} />
    </div>
  );
}
```

### `(admin)/admin/feedback/page.tsx`

```tsx
export default async function FeedbackPage({
  searchParams,
}: {
  searchParams: Promise<{ status?: string }>;
}) {
  const { status } = await searchParams;
  const filter = parseFeedbackFilter(status);
  const items = await listFeedback(filter);
  return (
    <div className="space-y-6">
      <h1 className="text-2xl font-semibold">{t.admin.feedback.title}</h1>
      <FeedbackFilterTabs active={filter} />
      {items.length === 0 ? (
        <EmptyState title={t.admin.feedback.empty} />
      ) : (
        <FeedbackList items={items} />
      )}
    </div>
  );
}
```

## `src/components/layout/admin-sidebar.tsx` (клон `sidebar.tsx`)

- `"use client"` (нужен `usePathname`), как у `Sidebar`.
- NAV:
  ```ts
  const NAV = [
    { href: "/admin", label: t.admin.nav.overview, icon: LayoutDashboard, exact: true },
    { href: "/admin/feedback", label: t.admin.nav.feedback, icon: MessageSquare },
  ] as const;
  ```
- **Активность:** для `exact` — строгое `pathname === href`; иначе
  `pathname === href || pathname.startsWith(href + "/")`. Без `exact` пункт
  `/admin` подсветился бы на `/admin/feedback`.
- Шапка — логотип + пометка админки (напр. `tutorOS · admin`).
- Низ — `ThemeToggle` + `signOutAction` (как в tutor-сайдбаре). Имя/почту админа
  можно не показывать (служебный аккаунт) или вывести email через `getCurrentUser`
  на сервере и прокинуть пропом — на усмотрение, тонко.

## Верификация (сводно)

1. **CI:** `pnpm lint && pnpm typecheck && pnpm test && pnpm build` — зелёные, без `any`.
2. **Миграция + типы:** `0012` применена (репейр истории перед `db push`),
   `database.types.ts` дополнен. RLS-проверки — [`01_data.md`](01_data.md) §«Проверка».
3. **e2e (Playwright, localhost:3000):**
   - вход админом → `/admin` → 4 карточки с верными числами;
   - `/admin/feedback` → список новейшие сверху; смена статуса в `<select>`
     сохраняется (после reload статус прежний); `?status=new` сужает список;
   - вход репетитором → ручной `/admin` → `/students`;
   - отправка из кнопки «Поддержка» по-прежнему работает (insert не сломан).
4. **Состояния:** пустой инбокс → `<EmptyState>`; брошенный запрос → `error.tsx`.
